Quartz는 기본적으로 `Explorer` 컴포넌트를 사용하여 왼쪽 사이드바에 사이트의 모든 파일과 폴더를 보여줍니다.
`quartz.layout.ts`에서 상세한 동작을 설정할 수 있습니다.

## 1. 기본 설정 (Basic Config)

`Component.Explorer({})` 안에 옵션을 넣어 제어합니다.

| 옵션명 | 기본값 | 설명 및 추천 값 |
| :--- | :--- | :--- |
| **`title`** | `"Explorer"` | 탐색기 상단에 표시될 제목. (예: `"Category"`, `"Menu"`) |
| **`folderClickBehavior`** | `"collapse"` | 폴더 클릭 시 동작.<br>• `"collapse"`: 접기/펼치기 (기본값)<br>• `"link"`: **폴더 노트(index.md)로 이동** (추천) |
| **`folderDefaultState`** | `"collapsed"` | 초기 상태.<br>• `"collapsed"`: 닫힘<br>• `"open"`: **모두 열림** |
| **`useSavedState`** | `true` | 사용자가 열고 닫은 상태를 브라우저에 저장할지 여부. |

## 2. 고급 설정 (Advanced)

자바스크립트 함수(`sort`, `map`, `filter`)를 사용하여 파일 목록을 내 마음대로 조작할 수 있습니다.

### ① 이름 꾸미기 (`mapFn`)
파일이나 폴더 이름 앞에 이모지를 붙이거나, 대문자로 바꿀 수 있습니다.

**예시: 폴더(📁)와 파일(📄) 아이콘 추가**
```typescript
Component.Explorer({
  mapFn: (node) => {
    if (node.isFolder) {
      node.displayName = "📁 " + node.displayName
    } else {
      node.displayName = "📄 " + node.displayName
    }
  },
})
````

### ② 순서 정렬 (`sortFn`)

기본값은 **"폴더 먼저, 그 다음 파일 가나다순"**입니다. 이를 변경할 수 있습니다.

**예시: 폴더/파일 구분 없이 무조건 가나다순 정렬**



```TypeScript
Component.Explorer({
  sortFn: (a, b) => {
    return a.displayName.localeCompare(b.displayName)
  },
})
```

### ③ 숨기기 (`filterFn`)

특정 파일이나 폴더를 탐색기 목록에서 아예 빼버릴 수 있습니다. (실제 파일은 존재함)

**예시: 특정 태그(`explorerexclude`)가 있는 파일 숨기기**



```TypeScript
Component.Explorer({
  filterFn: (node) => {
    return node.data?.tags?.includes("explorerexclude") !== true
  },
})
```

## 3. 적용 위치 (Layout)

Explorer 설정을 바꿀 때는 `quartz.layout.ts` 파일의 **두 군데**를 모두 수정해야 합니다.

1. **`defaultContentPageLayout`**: 일반 글을 볼 때의 레이아웃
    
2. **`defaultListPageLayout`**: 폴더나 태그 목록을 볼 때의 레이아웃
    

> **💡 팁:** 한쪽만 수정하면, 폴더를 클릭해서 들어갔을 때 탐색기 모양이 초기화되는 현상이 발생합니다. 반드시 두 곳 모두 똑같은 코드를 넣어주세요.
