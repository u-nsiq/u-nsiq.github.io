Quartz는 기본적으로 **SPA(Single Page Application)** 스타일의 라우팅을 지원합니다.
링크를 클릭했을 때 전체 페이지를 새로고침하지 않고, **변경된 내용만 부드럽게 교체**하여 사용자 경험(UX)을 극대화합니다.

## 1. 기능의 장점

* **깜빡임 방지:** 페이지 이동 시 화면이 하얗게 변했다가 다시 뜨는 현상(Flash of unstyled content)이 없습니다.
* **속도 향상:** 브라우저가 전체 페이지를 다시 로드하는 대신, 필요한 부분만 가져오므로 체감 속도가 훨씬 빠릅니다.

## 2. 작동 원리 (Technical Detail)

내부적으로 `micromorph`라는 라이브러리를 사용합니다.
1.  사용자가 링크를 클릭하면 페이지 이동을 가로챕니다(Hijack).
2.  백그라운드에서 `GET` 요청으로 다음 페이지의 HTML을 가져옵니다.
3.  현재 페이지와 새 페이지를 비교(Diff)하여 **달라진 부분만 선택적으로 갈아끼웁니다.**

## 3. 설정 방법

`quartz.config.ts` 파일의 `enableSPA` 옵션으로 제어합니다.

```typescript
// quartz.config.ts
const config: QuartzConfig = {
  configuration: {
    // ...
    enableSPA: true, // true: 부드러운 전환 켜기 (기본값/추천)
                     // false: 일반 웹사이트처럼 새로고침 방식
    // ...
  },
}
````

> **💡 참고:** 만약 특정 플러그인(예: 복잡한 자바스크립트가 들어간 외부 위젯)이 페이지 이동 후에 작동하지 않는다면, 이 기능을 `false`로 꺼야 할 수도 있습니다. 하지만 대부분의 경우 켜두는 것이 좋습니다.
