모든 노트를 다 공개할 필요는 없습니다. Quartz는 두 가지 방식을 통해 특정 글이나 폴더를 비공개로 설정할 수 있습니다.

## 1. 프론트매터 사용 (가장 쉬운 방법)

각 파일의 상단(`---`)에 설정을 추가하여 개별적으로 제어합니다.

### ① Draft (초안) 설정 (기본값)
`draft: true`라고 적으면 해당 글은 배포되지 않습니다. 기본적으로 `RemoveDrafts` 플러그인이 이를 처리합니다.

```yaml
---
title: "나만의 비밀 메모"
draft: true
---
````

### ② Whitelist 방식 (선택적 공개)

반대로 "기본적으로 다 숨기고, 내가 지정한 것만 공개"하고 싶다면 `ExplicitPublish` 플러그인을 사용해야 합니다. 이 경우 `publish: true`가 있는 글만 배포됩니다.

> **⚠️ 주의:** 이 방식은 마크다운 파일(`.md`)만 숨깁니다. 이미지나 PDF 같은 첨부파일은 여전히 빌드 폴더에 포함될 수 있습니다.

---

## 2. 폴더 통째로 무시하기 (`ignorePatterns`)

`quartz.config.ts` 파일에서 특정 폴더나 파일 패턴을 아예 Quartz가 읽지 못하게 막을 수 있습니다.

TypeScript

```
// quartz.config.ts
configuration: {
  // ...
  ignorePatterns: ["private", "templates", "*.tmp"],
  // ...
}
```

- **`private`**: `private`이라는 이름의 폴더나 파일 무시
    
- **`**/private`**: 어느 위치에 있든 `private` 이름을 가진 폴더 무시
    

---

## 3. 보안 주의사항 (GitHub)

위의 방법들은 **"블로그 웹사이트(HTML)"에 포함되지 않게 하는 것**뿐입니다.

만약 사용자님의 **GitHub 저장소(Repo)가 'Public(공개)' 상태**라면, 남들이 깃허브에 들어와서 소스 코드(`content` 폴더)를 볼 수 있습니다.

완벽한 보안을 원한다면:

1. GitHub 저장소를 **Private**으로 전환하거나,
    
2. 비공개할 파일들을 `.gitignore`에 추가하여 아예 깃허브에 올리지 말아야 합니다.
