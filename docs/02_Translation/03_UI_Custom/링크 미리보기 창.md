Quartz는 위키피디아(Wikipedia)와 유사하게, 링크 위에 마우스를 올리면(Hover) 해당 문서의 내용을 팝업으로 띄워줍니다.

## 1. 주요 기능

* **스크롤 지원:** 팝업 창 안에서 스크롤하여 문서 전체를 훑어볼 수 있습니다.
* **헤더 링크 지원:** `[[문서#헤더]]` 형태의 링크라면, 팝업이 떴을 때 해당 헤더 위치로 자동 스크롤됩니다.
* **이미지 미리보기:** 옵시디언처럼 위키링크로 연결된 이미지(`[[image.png]]`)도 팝업으로 볼 수 있습니다.
* **내부 문서 전용:** 보안 정책(CORS) 때문에 **블로그 내부의 링크**만 미리보기가 가능하며, 외부 사이트(네이버, 구글 등) 링크는 지원하지 않습니다.

---

## 2. 설정 방법 (Configuration)

이 기능은 `quartz.config.ts` 파일에서 켜고 끌 수 있습니다.

```typescript
// quartz.config.ts
const config: QuartzConfig = {
  configuration: {
    // ...
    enablePopovers: true, // true: 켜기 (기본값), false: 끄기
    // ...
  },
}
````

---

## 3. 개발자 정보 (Advanced)

### 작동 원리 (CSS Class)

Quartz는 HTML 요소 중 **`popover-hint`** 라는 클래스가 붙은 요소들만 긁어와서 미리보기 창에 띄웁니다.

기본적으로 제목, 읽는 시간(메타데이터), 태그, 그리고 본문 내용이 이 클래스를 가지고 있습니다.

### 커스텀 컴포넌트 적용

만약 사용자님이 직접 만든 컴포넌트(예: 커스텀 공지사항)도 미리보기 창에 뜨게 하고 싶다면, 해당 HTML 태그에 `class="popover-hint"`를 추가하면 됩니다.

### 스타일 수정

미리보기 창의 크기나 디자인을 바꾸고 싶다면 아래 파일을 수정하세요.

- **스타일:** `quartz/components/styles/popover.scss`
    
- **스크립트:** `quartz/components/scripts/popover.inline.ts`
