지식 증류는 크고 복잡한 Teacher 모델이 학습한 "지식"을 작고 효율적인 Student 모델로 전달하는 **모델 압축 기법**이다.

==왜 하필 '증류(Distillation)'인가?==

거대 모델이 학습한 지식을 작은 모델에게 전달하는 거면, 그냥 '지식 전이(Transfer)' 아닌가? 왜 하필 증류(Distillation)라는 단어가 붙었을지를 먼저 생각해 봐야 한다.

화학에서 증류(蒸溜)란,
'복잡한 혼합물(mixture)에 열을 가해 끓는점이 낮은 핵심 성분만 기화시켜 불순물은 버리고 핵심 정수만 순수하게 분리하는 과정'이다.
이 증류 개념을 이해할 때 중요한 건, 기화시키는 것이 불순물이 아니라는 점이다.
보통 '열을 가해서 나쁜 걸 날려 보낸다'고 생각하기 쉬운데, 증류에선 끓는점이 낮아서 가장 먼저 기화되는 수증기(vapor)가 우리가 추출하고자 하는 순도 높은 성분에 해당한다.

머신러닝의 지식 증류도 정확히 이 비유를 따른다.

## 무엇을 추출하는가? (다크 널리지)

그렇다면 머신러닝 모델을 끓여서 기화시키려는 대상은 무엇일까?
원형적인 지식 증류(로짓 기반)에서는, 작은 모델에게 넘겨주려는 지식은 **대형 모델의 최종 예측값(출력 확률)** 이다.

대형 모델의 출력값에는 단순히 정답만 있는 것이 아니라, 각 클래스에 대해 매긴 점수 분포가 들어있다. 즉, 클래스 간의 관계성이 녹아있다.
이 대형 모델이 품고 있는 이 미묘한 정보량의 정수를 [[Hard Label & Soft Target#정보량의 차이 Dark Knowledge|다크 널리지(Dark Knowledge)]]라고 부르며, 이것이 바로 우리가 추출하려는 대상이다.

즉, 지식 증류는 대형 모델로부터 '다크 널리지'를 추출하여 이를 작은 모델로 넘긴다고 이해할 수 있다.

## 어떻게 추출할까? (온도 T)

대형 모델로부터 '다크 널리지'를 추출하기 위해, **온도(Temperature, $T$)** 라는 파라미터를 도입한다.
'증류'라는 메타포에 걸맞게, 대형 모델의 출력값에 열을 가하여 핵심 정수만 분리하는 것이다.

보통 잘 학습된 대형 모델은 확신이 너무 강한 상태다.
결괏값인 [[로짓 (Logit)]]을 일반적인 [[소프트맥스 함수 (Softmax Function)]]에 통과시키면 정답 확률만 99.9%로 극단적으로 부풀려지고, 우리가 원하는 오답 확률(다크 널리지)은 거의 0에 가깝게 짓눌려버린다.
작은 모델이 이렇게 짓눌린 미세한 확률값들을 학습 신호로 유의미하게 흡수하려면, 이 미세한 오답 확률을 부풀려 확률 분포를 강제로 둥글둥글하게 만들 필요가 있다.

즉, 소프트맥스 자체가 부드러운 함수이긴 하지만, 학습이 잘 된 대형 모델은 확신이 너무 강해 Hard Label처럼 딱딱한 결과를 출력하고, 지식 증류는 이에 열을 가해서 Soft Target 상태로 녹여주는 역할이라고 이해하면 된다.

다음은 소프트맥스 함수에 온도 파라미터를 추가하여 변형한 형태다:

$$
q_i = \frac{\exp(z_i / T)}{\sum_j \exp(z_j / T)}
$$

- **차가운 상태 ($T=1$):** 일반적인 소프트맥스. 뾰족하고 딱딱한 분포라 다크 널리지가 수면 위로 드러나지 않는다.
- **온도를 높여 가열 ($T > 1$):** 수식에 열을 가하면, 오답 클래스들의 미세한 확률값들이 커지게 된다. 뾰족했던 기존 소프트맥스 함수의 확률 분포가 더 둥글둥글해지며, 클래스 간의 숨겨진 관계성(엑기스)이 선명하게 기화되어 나온다.

이렇게 대형 모델의 최종 출력에 열을 가해 뽑아낸 풍성하고 부드러운 형태의 정답지가 [[Hard Label & Soft Target|Soft Target]]이다.

## 응결: Student 모델의 학습

작은 모델(Student)은 이렇게 열을 받아 피어오른 부드러운 수증기(Soft Target)를 자신의 정답지로 삼아 학습한다. 단순한 100%짜리 정답지([[Hard Label & Soft Target|Hard Label]])가 아니라, 대형 모델이 포함하고 있던 '미묘한 관계성'까지 온전히 자신의 가중치로 흡수(응결)하는 것이다.

이때 Student 모델 역시 자신의 출력값에 동일한 온도 $T$를 가하여 부드러운 분포를 만든 뒤, Teacher의 Soft Target 분포와 얼마나 비슷한지 그 차이(Loss)를 줄이는 방향으로 학습을 진행한다.

## 손실 함수

Student는 두 가지 신호를 동시에 학습한다.

$$
L = \alpha \cdot L_{\text{Distillation}} + (1 - \alpha) \cdot L_{\text{Student}}
$$

- **$L_{\text{Distillation}}$**: Teacher의 Soft Target과 Student 출력 간 차이. KL 발산(KL Divergence)을 주로 사용한다.
- **$L_{\text{Student}}$**: Student 출력과 실제 Hard Label 간 차이. 크로스 엔트로피(Cross-Entropy)를 주로 사용한다.
- **$\alpha$**: 두 손실 간 비중을 조절하는 하이퍼파라미터.

Teacher의 세계관(Soft Target)과 실제 정답(Hard Label), 두 신호를 동시에 보며 학습한다.

## 증류 대상의 확장 (지식 증류의 종류)

Soft Target을 증류하는 것은 결과물을 작은 모델에 주는 것이다.
결과물이 아닌 '대형 모델이 생각하는 과정이나 구조 자체'를 증류하는 다른 방식도 있다.

지식 증류는 어떤 것(What)을 증류하는가, 어떻게(How) 증류하는가에 따른 두 축으로 나뉘게 된다:

| 분류 기준            | 방식    | 비고                                                |
| :--------------- | :---- | :------------------------------------------------ |
| **어떤 것을 (What)** | 로짓 기반 | 대형 모델의 최종 출력 확률(Soft Target) 모방 (Hinton의 오리지널 방식) |
|                  | 피처 기반 | 대형 모델의 은닉층에서 나오는 특징 맵(Feature Map) 자체를 모방         |
|                  | 관계 기반 | 개별 데이터가 아니라, 데이터들 사이의 거리나 관계 구조를 학습               |
| **어떻게 (How)**    | 오프라인  | 학습된 Teacher를 고정해 두고 Student를 학습시킴                 |
|                  | 온라인   | Teacher와 Student가 동시에 학습하며 서로 영향을 주고받음            |
|                  | 셀프 증류 | Teacher 없이, 내 모델의 깊은 층 지식을 얕은 층으로 스스로 전달          |
