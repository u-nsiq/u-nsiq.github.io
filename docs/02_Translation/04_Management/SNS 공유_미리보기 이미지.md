카카오톡, 슬랙, 트위터(X) 등에 블로그 링크를 공유할 때 나타나는 **미리보기 카드(썸네일 이미지, 제목, 설명)** 를 자동으로 생성해 주는 기능입니다.

## 1. 기능 소개

Quartz는 **모든 페이지마다** 그 페이지의 제목과 내용을 바탕으로 새로운 커버 이미지를 동적으로 생성합니다.
일일이 썸네일을 만들 필요 없이, 글만 쓰면 자동으로 멋진 공유 이미지가 생깁니다.

## 2. 디자인 (Showcase)

사이트의 테마 설정(라이트/다크)에 맞춰 이미지도 두 가지 버전으로 생성될 수 있습니다.

* **Light Mode:** 밝은 배경의 깔끔한 썸네일
* **Dark Mode:** 어두운 배경의 차분한 썸네일 
## 3. 설정 방법 (Configuration)

이 기능은 **`CustomOgImages`** 플러그인이 담당합니다.
`quartz.config.ts` 파일의 `emitters` (방출기) 목록에 이 플러그인이 포함되어 있는지 확인하세요.

```typescript
// quartz.config.ts

emitters: [
  Plugin.CustomOgImages(), // 이 줄이 있어야 썸네일이 자동 생성됨
  // ...
]
````

> **💡 참고:** 폰트 설정이나 색상을 바꾸고 싶다면 `CustomOgImages` 플러그인의 세부 옵션을 수정하면 됩니다. (플러그인 명세서 참고)
