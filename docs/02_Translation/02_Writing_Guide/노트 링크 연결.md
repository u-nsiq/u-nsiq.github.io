Quartz는 옵시디언의 강력한 링크 기능을 웹에서도 그대로 구현합니다.
내가 다른 노트를 언급하는 **위키링크(Wikilinks)** 와, 다른 노트가 나를 언급한 **백링크(Backlinks)** 기능을 모두 지원합니다.

---

## 1. 위키링크 (Wikilinks) - 다른 노트 연결하기

`[[ ]]` 대괄호 두 개를 사용하여 다른 문서나 이미지를 쉽고 빠르게 연결할 수 있습니다. `CrawlLinks` 플러그인이 이 링크들을 자동으로 찾아 웹 페이지로 변환해 줍니다.

### 기본 문법 (Syntax)

| 문법                        | 설명                      | 예시                                 |
| :------------------------ | :---------------------- | :--------------------------------- |
| **`[[파일 이름]]`**           | 가장 기본적인 링크 연결.          | `[[운영체제]]` → [운영체제]로 표시됨           |
| **`[[파일 이름 \| 대체 텍스트]]`** | 링크 텍스트를 다르게 표시 (Alias). | `[[운영체제 \| OS 공부]]` → [OS 공부]로 표시됨 |
| **`[[파일 이름#헤더]]`**        | 특정 문단(제목)으로 바로 이동.      | `[[운영체제#프로세스]]`                    |
| **`[[파일 이름#^블록ID]]`**     | 특정 블록(문장)으로 바로 이동.      | `[[운영체제#^ref1]]`                   |

### 임베드 (Embeds) - 내용 불러오기
링크 앞에 느낌표 `!`를 붙이면, 링크를 클릭하는 게 아니라 **그 내용을 현재 문서에 가져와서 보여줍니다(Transclusion).**

* **이미지 삽입:**
    * `![[image.png]]`: 이미지 원본 크기로 삽입
    * `![[image.png|100x145]]`: 가로 100px, 세로 145px로 리사이징
* **노트 삽입:**
    * `![[운영체제]]`: '운영체제' 노트의 **전체 내용**을 여기에 보여줌
    * `![[운영체제#프로세스]]`: '프로세스' **챕터(헤더)만** 가져와서 보여줌
    * `![[운영체제#^block]]`: 특정 **블록만** 가져와서 보여줌

---

## 2. 백링크 (Backlinks) - 나를 언급한 노트 보기

백링크란 **"현재 이 노트를 링크하고 있는 다른 노트들의 목록"**입니다.
보통 페이지 오른쪽 사이드바나 하단에 표시되며, 마우스를 올리면 미리보기(Popover)도 지원합니다.

### 설정 방법 (Customization)

`quartz.layout.ts` 파일에서 백링크 컴포넌트를 설정할 수 있습니다.

```typescript
// quartz.layout.ts

Component.Backlinks({
  hideWhenEmpty: true // (기본값) 백링크가 하나도 없으면 아예 숨김
})
````

- **항상 표시하기:** 백링크가 없더라도 "No backlinks found" 메시지와 함께 영역을 유지하고 싶다면 `hideWhenEmpty: false`로 설정하세요.
    
- **제거하기:** 레이아웃 파일에서 `Component.Backlinks()` 줄을 삭제하면 됩니다.
