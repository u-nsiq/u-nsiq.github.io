## 2. 드로어 레이아웃 시스템

### 2-1. 배경과 목적

**문제**: 화면 분할이나 75~80% 배율에서 1200px 미만이 되면 Quartz가 "모바일 모드"로 전환되는데, 이 모드에서 탐색기(Explorer)가 화면 전체를 덮는 방식으로 동작하여 콘텐츠가 잘리거나 레이아웃이 어색해짐.

**해결 방향**: 1200px 미만에서는 사이드바를 없애고 **본문만 표시**. 대신 버튼으로 슬라이드 패널(드로어)을 열어서 Explorer/TOC에 접근.

- 왼쪽 버튼(☰) → Explorer 슬라이드 패널
- 오른쪽 버튼(≡) → TOC + Graph + Backlinks 슬라이드 패널

### 2-2. `collapsed` vs `panel-open` — 핵심 개념

Quartz에는 탐색기 접기/펼치기를 위한 **`.collapsed` 클래스**가 있다:
- `.explorer.collapsed` = 탐색기 접힘
- 버튼 클릭, 페이지 이동(nav), 화면 크기 변화(resize) 이벤트 등 여러 곳에서 자동으로 토글됨

이 `.collapsed`를 그대로 쓰면 문제가 생긴다:  
→ 드로어를 열어놔도 **배율을 바꾸면 resize 이벤트가 자동으로 `.collapsed`를 추가**해 드로어가 닫혀버림.

그래서 **`.panel-open`이라는 새 클래스를 별도로 만들었다**:
- `.explorer.panel-open` = 왼쪽 드로어 열림
- `.toc.panel-open` = 오른쪽 드로어 열림
- CSS에서 `:has(.explorer.panel-open)` 셀렉터로 드로어 위치를 슬라이드

```
[버튼 클릭]     → panel-open 토글
[페이지 이동]   → panel-open 제거 (자동 닫힘)
[오버레이 클릭] → panel-open 제거 (배경 터치로 닫힘)
[zoom/resize]  → 아무 일도 없음 ✓
```

### 2-3. CSS 작동 방식 (`custom.scss` §1)

1200px 미만에서:

```
기본 상태:
  .sidebar.left  → position: fixed, left: -320px  (화면 왼쪽 바깥에 숨김)
  .sidebar.right → position: fixed, right: -320px (화면 오른쪽 바깥에 숨김)

panel-open 상태:
  .sidebar.left:has(.explorer.panel-open)  → left: 0   (슬라이드 인)
  .sidebar.right:has(.toc.panel-open)      → right: 0  (슬라이드 인)
```

**오버레이**: 드로어 열릴 때 배경을 어둡게 덮는 반투명 딤 레이어.  
`body::after`를 사용 (Quartz CSS와 충돌 없음 확인).

```
z-index 구조:
  201 — 드로어 버튼 (항상 최상단)
  200 — 드로어 패널 (.sidebar.left / .sidebar.right)
  199 — 오버레이 (body::after, 패널 아래/콘텐츠 위)
```

버튼은 `position: fixed`로 뷰포트에 고정 (부모가 off-screen에 있어도 항상 보임):
- 햄버거 버튼(☰): 좌상단 고정 (`top: 1rem; left: 1rem`)
- TOC 버튼(≡): 우상단 고정 (`top: 1rem; right: 1rem`)

**버튼 인터랙션 상태**:

| 상태 | 시각 효과 |
|---|---|
| 기본 | 흰 배경, 연한 테두리 |
| 호버 | 배경 `--lightgray`, 테두리 `--gray` |
| 패널 열림 | 배경 `--secondary`(슬레이트 블루)로 반전, 아이콘 흰색 |
| 패널 열림 + 호버 | 배경 `--tertiary` |

패널 열림 상태 감지: `.explorer.panel-open button.mobile-explorer` — JS 없이 CSS만으로 처리.  
배경색·테두리·SVG stroke 모두 `transition: 150ms ease`.

### 2-4. 줌 인 시 드로어 레이아웃 깨짐 버그 수정

**원인**: Quartz `$mobile` 브레이크포인트(`800px`)가 드로어 브레이크포인트(`1200px`)보다 좁아서, 드로어가 열린 상태에서 배율을 올리면 CSS 픽셀 뷰포트가 800px 아래로 내려가며 Quartz 원본 `$mobile` 스타일이 추가 발동됨.

발동되는 문제 스타일:
- `base.scss`: `.sidebar.left { flex-direction: row; gap: 0; height: unset; }` → 세로 레이아웃 붕괴
- `explorer.scss`: `.explorer { flex: 0 0 34px; overflow: hidden; order: -1; margin-top: auto; }` → 탐색기가 34px로 찌그러지고 순서 역전
- `base.scss`: `MobileOnly(Spacer)` 표시 → `flex: 1`로 공간 전체 차지 → 검색/탐색기 아래로 밀림

**수정 내용** (`custom.scss`):
1. `.sidebar.left` 주요 속성에 `!important` 보강 (`height`, `overflow-y`, `margin`)
2. `.sidebar.left .mobile-only { display: none !important }` 추가 (드로어 내 Spacer 숨김)
3. `.sidebar.left .explorer` 속성 보강 (`flex`, `height`, `overflow-y`, `order`, `align-self`, `margin`)
4. `@media (max-width: 799px)` 전용 리셋 블록 추가 (§1-B) — 위 모든 사항을 800px 미만에서 명시적으로 재선언

### 2-5. 관련 파일 목록

| 파일 | 역할 | 충돌 주의 |
|---|---|---|
| `quartz/styles/custom.scss` | 드로어 CSS, 오버레이 (§1 섹션) | — |
| `quartz/components/scripts/explorer.inline.ts` | 왼쪽 드로어 JS, 오버레이 클릭 핸들러 | ⚠️ |
| `quartz/components/scripts/toc.inline.ts` | 오른쪽 드로어 JS | ⚠️ |
| `quartz/components/TableOfContents.tsx` | TOC 버튼 HTML | ⚠️ |
| `quartz.layout.ts` | TOC DesktopOnly 제거 | — |

## 3. Explorer 커스텀 기능

### 3-1. 폴더 파일 카운트 표시

**보이는 것**: `📁 Posts` `[12 gray]` `[+3 blue]`

- `12` (회색) = 폴더 전체 파일 수
- `+3` (secondary 컬러) = 최근 7일 이내 `date` 갱신된 파일 수 (없으면 표시 안 함)

**어떻게**:
- `countFiles(node)` → `.folder-count` span (회색)
- `countRecentFiles(node, cutoff)` → `.folder-count-recent` span (있을 때만 생성)
- `mapFn` (`quartz.layout.ts`)은 폴더 이름에 `📁 ` 이모지만 추가. 카운트 로직은 모두 `explorer.inline.ts`에서 처리
- CSS: `explorer.scss`의 `.folder-count` / `.folder-count-recent` 스타일

### 3-2. `folderStateOverrides` 지원

**역할**: 특정 폴더의 초기 열림/닫힘 상태를 설정 파일에서 지정.  
(`quartz.layout.ts`에서 `Notes: collapsed`, `Posts: open` 설정)

**기술적 처리**:
1. `Explorer.tsx`에 `folderStateOverrides` 옵션 추가 → HTML `data-state-overrides` 속성에 JSON 직렬화
2. `explorer.inline.ts`에서 JSON 파싱 → 저장된 상태 없으면 override → 기본값 순서로 적용

### 3-3. 폴더 클릭 UX 개선 (⚠️ `explorer.inline.ts`, `explorer.scss`)

**변경 전**: 폴더명 클릭 → index.md 이동 / 왼쪽 화살표 클릭 → 하위 목록 토글  
**변경 후**: 폴더명 클릭 → 하위 목록 토글 / hover 시 링크 아이콘 클릭 → index.md 이동

**구현 방식**:
- `toggleFolderFromLink()` 함수 추가: `<a.folder-title>` 클릭 시 `preventDefault()` 후 `toggleFolder()` 호출
- `setupExplorer()`에서 `folderClickBehavior === "link"` 일 때 `.folder-title` 에 핸들러 등록
- 링크 아이콘: `<span class="folder-link-icon-wrap"><a>SVG</a></span>` 구조로 추가  
  → `<span>` 래퍼 필수: `div > a` CSS 셀렉터 충돌 방지 (이전 시도에서 `<a>→<button>` 교체가 CSS 충돌 유발했던 점 반영)
- 링크 아이콘 스타일: 기본 `opacity: 0.4` 상시 노출, hover 시 `0.8`

**Explorer 스타일 조정** (`explorer.scss`):
- `.folder-count`: `0.7rem` → `0.75rem`
- `.folder-count-recent`: 텍스트 → pill 배지 (`background: var(--secondary)`, 흰 텍스트, `border-radius: 999px`)
- 링크 아이콘 SVG 크기: `14px`

### 3-4. 드로어 버튼 바인딩 (⚠️ `explorer.inline.ts`)

**버튼 분기**:

```
data-mobile="true"  → toggleExplorerPanel() — panel-open 토글
data-mobile 없음    → toggleExplorer()       — collapsed 토글 (데스크탑용)
```

**nav 이벤트**: 페이지 이동 시 `panel-open` 제거  
**resize 핸들러**: 내용 비움 (zoom/resize에 드로어가 닫히지 않도록)  
**오버레이 클릭 핸들러**: 모듈 레벨에 `document` 클릭 이벤트 등록. 클릭 target이 `.sidebar.left`/`.sidebar.right` 바깥이면 해당 패널 닫음.

커스텀 코드 위치: `// [커스텀]` ~ `// [커스텀 끝]` 마커로 구분

### 3-5. `contentIndex.tsx` 날짜 필드 유지 (⚠️)

**변경**: `simplifiedIndex` 생성 시 `delete content.date` 제거

**이유**: Explorer의 `sortFn` / `countRecentFiles`가 클라이언트에서 `node.data.date`로 날짜에 접근해야 함.

## 4. 콘텐츠 스타일 (`custom.scss` §2, `explorer.scss`)

### Explorer 스타일

- 파일 항목 폰트 크기: `0.75rem`, `display: block`으로 클릭 영역 확장
- 파일 항목 hover/active: 배경 `var(--highlight)` — 현재 페이지 항목도 색상 유지
- 폴더 카운트: `.folder-count` `0.7rem` 회색, `.folder-count-recent` `0.65rem` secondary blue (⚠️ `explorer.scss` 직접 수정)

### 콘텐츠 스타일

| 항목 | 설명 |
|---|---|
| 본문 폰트 굵기 | `article { font-weight: 450 }` (Pretendard Medium 근사) |
| 볼드 굵기 | `article strong { font-weight: 700 }` — 450 본문 기준 명확한 대비 |
| `[[내부 링크]]` 색상 | `article a.internal { color: var(--dark) }` — 라이트모드 가독성 개선 (`#7797C0` → `#202020`) |
| `==하이라이트==` | 라이트: `font-weight: 600` / 다크: `color: #1a1a1a; font-weight: 600` (노란 배경 가독성) |
| 다크모드 `textHighlight` | `rgba(255, 214, 0, 0.55)` 노란색 (라이트모드는 `#CCE9FF` 파란색 유지) |
| Bulleted list indent guide | 중첩 목록 왼쪽에 Obsidian 스타일 세로 라인 |
| Inline code 색상 | 라이트: `rgb(233, 49, 58)` / 다크: `rgb(255, 110, 110)` (어두운 배경에서 가독성 확보) |
| 텍스트 드래그 선택 | 라이트: `rgba(0,0,0,0.12)` / 다크: `rgba(255,255,255,0.15)` |

### `Head.tsx` 폰트 로딩

`fontOrigin: "local"` 설정 시 Quartz는 폰트를 로드하지 않음.  
`Head.tsx`에 직접 `<link>` 태그 추가:
- Pretendard: `cdn.jsdelivr.net/gh/orioncactus/pretendard/dist/web/static/pretendard.min.css`
- Schibsted Grotesk: Google Fonts CDN
- IBM Plex Mono: Google Fonts CDN

## 6. 업스트림 업데이트 시 체크리스트

Quartz를 `npx quartz update`로 업데이트할 때 충돌 가능성 있는 파일:

| 파일 | 커스텀 내용 | 위치 마커 |
|---|---|---|
