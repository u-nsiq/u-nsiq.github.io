## quartz/components/scripts/explorer.inline.ts (커스텀 수정)

> **업데이트 충돌 주의**: 핵심 클라이언트 스크립트 수정

### 추가된 기능

1. **폴더 파일 카운트 표시**
   - `countFiles(node)` 재귀 함수 추가
   - `createFolderNode`에서 `.folder-count` span 생성 후 titleContainer에 append
   - link/collapse 모드 양쪽 모두 적용

2. **`folderStateOverrides` 지원**
   - `ParsedOptions`에 `stateOverrides: Record<string, boolean>` 추가
   - `setupExplorer`에서 `data-state-overrides` JSON 파싱
   - `currentExplorerState` 초기화 시 저장 상태 없으면 override → 기본값 순으로 적용

3. **resize 핸들러 버그 수정**
   - 기존: 탐색기가 열린 채로 모바일 breakpoint(800px)를 넘으면 모바일 전체화면 오버레이가 갑자기 나타남
   - 수정: 모바일 모드 진입 감지 시(`mobileExplorer.checkVisibility()`) 탐색기 자동 닫기

## quartz/plugins/emitters/contentIndex.tsx (커스텀 수정)

> **업데이트 충돌 주의**: 업스트림 파일 직접 수정

- `simplifiedIndex` 생성 시 `delete content.date` 제거 → contentIndex.json에 `date` 필드 유지
- 이유: Explorer의 `sortFn` / `mapFn`이 클라이언트에서 `node.data.date`로 날짜 접근하기 위함
- 기본값은 RSS 최적화를 위해 date를 제거하지만, 날짜 기반 정렬/배지 기능에 필요

## 변경하지 않은 것

- `quartz.config.ts`: `enableSPA`, `enablePopovers`, `locale`, `ignorePatterns`, `cdnCaching`
- `quartz.layout.ts`: `Head` (폰트 로딩 외), `ArticleTitle`, `ContentMeta`, `TagList`, `PageTitle`, `Search`, `Darkmode`, `TOC`, `Backlinks`
- Emitters/Filters: 전부 Default
