Quartz는 블로그에 **최근 작성되거나 수정된 글의 목록**을 자동으로 생성해 주는 컴포넌트를 제공합니다.
이 기능은 기본적으로 켜져 있지 않으므로, `quartz.layout.ts` 파일에 직접 추가해야 합니다.

## 1. 활성화 및 설정 (Configuration)

`quartz.layout.ts` 파일에서 `Component.RecentNotes()`를 원하는 위치(예: 오른쪽 사이드바, 혹은 메인 페이지)에 추가합니다.

### 주요 옵션
다양한 옵션을 통해 입맛대로 설정할 수 있습니다.

```typescript
// quartz.layout.ts

Component.RecentNotes({
  title: "최근 작성한 글",        // 제목 변경 (기본값: "Recent notes")
  limit: 5,                      // 보여줄 글 개수 (기본값: 5)
  showTags: true,                // 태그 표시 여부 (기본값: true)
  linkToMore: "tags/research",   // '더 보기' 링크 연결 (예: 특정 태그 페이지로 이동)
})
````

---

## 2. 고급 필터링 (Filter)

단순히 모든 최신 글을 보여주는 게 아니라, **특정 폴더나 조건을 만족하는 글만** 보여줄 수도 있습니다.

연구생이시라면 **"연구 노트"만 따로 메인에 띄우는 용도**로 쓰기 좋습니다.

**예시: 'study' 폴더에 있는 글만 보여주기**


```TypeScript
Component.RecentNotes({
  limit: 3,
  filter: (f) => f.slug!.startsWith("study/")
})
```

---

## 3. 정렬 순서 (Sort)

기본적으로 **날짜순(최신순)** 으로 정렬되며, 날짜가 같으면 제목순으로 정렬됩니다.

만약 다른 기준으로 정렬하고 싶다면 `sort` 함수를 커스터마이징할 수 있습니다.
