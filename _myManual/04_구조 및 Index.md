이 문서는 폴더와 태그가 웹사이트에서 어떻게 표현되는지, 그리고 특정 페이지를 숨기거나 목차를 관리하는 방법을 다룹니다.

---

## 1. 폴더 인덱스 (Folder Listings)
Quartz는 폴더 구조를 그대로 웹페이지로 만듭니다. 특정 폴더에 접속했을 때 보이는 "대문 페이지"를 설정하는 방법입니다.

### 기본 동작
* Quartz는 모든 폴더에 대해 **인덱스 페이지**를 자동으로 생성합니다.
* 하위 폴더(Subfolders)가 있다면 그 역시 별도의 페이지로 생성됩니다.
* **기본 제목:** `Folder: 폴더명`으로 자동 설정되며, 설명은 비어있습니다.

### 폴더 대문 꾸미기 (Folder Note)
폴더에 들어갔을 때 보이는 제목과 설명을 내 마음대로 바꾸려면, 해당 폴더 안에 `index.md` 파일을 만듭니다.

**예시: `content/posts` 폴더 꾸미기**
1. `content/posts/index.md` 파일을 생성합니다.
2. Frontmatter에 `title`을 적고, 본문에 설명을 적습니다.
   ```yaml
   ---
   title: "내 게시물 모음"
   ---
   여기는 제가 작성한 모든 게시물이 있는 곳입니다.
   ```

3. 이제 `/posts`로 접속하면 "내 게시물 모음"이라는 제목과 설명이 뜹니다.

### 폴더로 링크 걸기

다른 문서에서 폴더 페이지로 링크를 걸 때는 **폴더 이름 뒤에 슬래시(`/`)** 를 붙여야 합니다.

- 작성법: `[[posts/]]` (결과: posts 폴더 인덱스로 이동)

## 2. 태그 인덱스 (Tag Listings)

태그를 클릭했을 때 보이는 "모아보기 페이지"를 관리하는 방법입니다.

### 기본 동작

- Quartz는 사용된 모든 태그에 대해 인덱스 페이지를 생성합니다.
- `/tags` 주소로 접속하면 전체 태그 목록을 볼 수 있습니다.
- **계층형 태그:** `plugin/emitter` 처럼 슬래시를 쓴 태그도 단계별로 페이지가 생성됩니다.

### 태그 대문 꾸미기

특정 태그(예: `#CS`) 페이지에 설명을 추가하고 싶다면, `content/tags/` 폴더에 마크다운 파일을 만듭니다.

**예시: `#CS` 태그 페이지 꾸미기**

1. `content/tags/CS.md` 파일을 생성합니다.
2. 제목과 설명을 작성합니다.
    ```YAML
    ---
    title: "컴퓨터 과학 (CS)"
    ---
    CS 전공 지식을 정리한 태그입니다.
    ```
    

### 태그로 링크 걸기

태그 페이지로 바로 가는 링크를 만들 때는 `tags/` 접두어를 붙입니다.

- 작성법: `[[tags/plugin]]`

## 3. 비공개 설정 (Private Pages)

작성 중이거나 개인적인 메모를 웹사이트에 노출하지 않는 방법입니다.

### 방법 A: Draft 설정 (추천)

Frontmatter에 `draft: true`를 추가합니다.

- 로컬 미리보기(`--serve`)에서는 보이지만, 배포(`sync`) 시에는 제외됩니다.
    
- **주의:** 이미지나 PDF 같은 **비-마크다운 파일**은 draft 설정과 상관없이 업로드될 수 있습니다.

### 방법 B: 아예 무시하기 (Ignore Patterns)

특정 폴더나 파일 패턴을 Quartz가 아예 쳐다보지도 않게 설정합니다.

`quartz.config.ts` 파일의 `ignorePatterns` 항목을 수정합니다.

- `*.md`: 모든 마크다운 제외
- `**/private`: 어느 위치든 `private`이라는 이름의 폴더나 파일은 전부 제외.
- `!(*.md)`: 마크다운이 **아닌** 파일들 제외.

## 4. 목차 (Table of Contents)

우측 사이드바에 표시되는 목차 설정입니다.

### 기본 동작

- `H1`(#) 부터 `H3`(###) 까지의 헤더를 자동으로 수집하여 보여줍니다.
- 헤더가 2개 이상일 때만 표시됩니다.
- 스크롤 위치에 따라 현재 읽고 있는 부분이 하이라이트됩니다.
- `TableOfContents` 플러그인에서 기본 동작 변경이 가능합니다.
### 목차 숨기기

특정 페이지에서만 목차를 끄고 싶다면 Frontmatter에 설정을 추가합니다.


```YAML
---
enableToc: false
---
```
