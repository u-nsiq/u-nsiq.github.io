Quartz는 별도의 설정 없이도 **다크 모드**를 완벽하게 지원합니다.
기본적으로 사용자의 **OS 시스템 설정(라이트/다크)** 을 따라가며, 사용자가 버튼을 눌러 모드를 바꾸면 브라우저 저장소(Local Storage)에 저장하여 다음 방문 때도 유지합니다.

## 1. 레이아웃 설정 (Layout)

`quartz.layout.ts` 파일에서 다크모드 버튼을 넣거나 뺄 수 있습니다.
보통은 왼쪽 사이드바(`left`)의 상단이나, 헤더 영역에 배치합니다.

```typescript
// quartz.layout.ts

Component.Flex({
  components: [
    // ... 다른 컴포넌트들
    { Component: Component.Darkmode() }, // 다크모드 토글 버튼
  ],
})
````

- **제거하기:** 만약 다크모드를 아예 쓰고 싶지 않거나 버튼을 숨기고 싶다면, `quartz.layout.ts`에서 `Component.Darkmode()` 코드를 모두 지우면 됩니다.
    

---

## 2. 고급 설정 (Event Listener)

테마가 바뀔 때마다 **특정 자바스크립트 코드를 실행**하고 싶다면 `themechange` 이벤트를 리스닝할 수 있습니다.

(예: 테마 변경 시 댓글창 색상도 같이 바꾸거나, 커스텀 그래프 색상을 변경할 때 유용)



```JavaScript
document.addEventListener("themechange", (e) => {
  console.log("테마가 변경되었습니다: " + e.detail.theme) // "light" 또는 "dark" 출력
  
  if (e.detail.theme === "dark") {
    // 다크모드일 때 실행할 로직
  } else {
    // 라이트모드일 때 실행할 로직
  }
})
```

> **💡 참고:** 다크모드와 라이트모드의 구체적인 **색상(Color Hex)**은 `quartz.config.ts`의 `theme` 섹션에서 수정할 수 있습니다.
