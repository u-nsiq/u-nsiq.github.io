Quartz는 사용자가 만든 폴더 구조와 태그를 바탕으로 자동으로 **목록(인덱스) 페이지**를 생성합니다.
방문자가 특정 주제의 글을 한눈에 모아볼 수 있게 해줍니다.

## 1. 폴더 목록 (Folder Listings)

Quartz는 모든 폴더에 대해 인덱스 페이지를 만듭니다.
예를 들어 `content/abc/def/note.md`라는 파일이 있다면, `abc` 폴더 페이지와 `abc/def` 폴더 페이지가 모두 생성됩니다.

### 폴더 페이지 꾸미기 (`index.md`)
기본적으로 폴더 페이지의 제목은 `Folder: 폴더명`으로 자동 설정됩니다.
이것을 내 마음대로 바꾸고 싶다면, 해당 폴더 안에 **`index.md`** 파일을 만드세요.

* **제목 변경:** `index.md`의 프론트매터 `title`을 수정하면 폴더 페이지 제목이 바뀝니다.
* **설명 추가:** `index.md` 본문에 내용을 적으면, 파일 목록 위에 그 내용이 설명으로 표시됩니다.

**예시 (`content/posts/index.md`):**
```markdown
---
title: "나의 개발 일지"
---
여기에는 제가 공부한 개발 기록들이 모여 있습니다.
````

### 폴더 링크하기

다른 글에서 폴더 목록 페이지로 링크를 걸고 싶다면, 폴더 이름 뒤에 슬래시(`/`)를 붙여서 링크합니다.

예: `[[research/]]` -> Research 폴더 목록으로 이동

---

## 2. 태그 목록 (Tag Listings)

Quartz는 사용된 모든 태그에 대해 목록 페이지를 생성합니다.

또한 계층형 태그(예: `#plugin/emitter`)를 지원하며, 상위 태그(`plugin`)와 하위 태그(`emitter`) 페이지를 각각 따로 만듭니다.

- **전체 태그 목록:** `/tags` 주소로 접속하면 블로그의 모든 태그 목록을 볼 수 있습니다.
    

### 태그 페이지 꾸미기

특정 태그 페이지(예: `#component`)에 제목이나 설명을 추가하고 싶다면, **`content/tags/`** 폴더 안에 태그 이름과 같은 마크다운 파일을 만드세요.

**예시 (`content/tags/component.md`):**



```Markdown
---
title: "컴포넌트 관련 글"
---
Quartz의 UI 컴포넌트들을 정리한 태그입니다.
```

### 태그 링크하기

다른 글에서 특정 태그 페이지로 링크를 걸 때는 `tags/태그명` 형식을 사용합니다.

예: `[[tags/plugin]]` -> #plugin 태그 목록으로 이동

---

## 3. 정렬 순서 (Customization)

폴더나 태그 페이지에 표시되는 글 목록의 정렬 순서를 바꾸고 싶다면, `quartz.config.ts`에서 플러그인 설정을 수정해야 합니다.

- **폴더:** `FolderPage` 플러그인 담당
    
- **태그:** `TagPage` 플러그인 담당
