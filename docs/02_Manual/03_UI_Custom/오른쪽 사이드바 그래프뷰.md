Quartz는 기본적으로 페이지 오른쪽에 **지식 그래프(Graph View)** 를 보여줍니다.
노트 간의 연결 관계를 시각화하며, 옵시디언처럼 **현재 글 중심의 로컬 뷰**와 **전체 글을 보여주는 글로벌 뷰**를 전환할 수 있습니다.

## 1. 두 가지 모드 (Local vs Global)

그래프 창 우측 상단의 아이콘을 클릭하여 모드를 전환할 수 있습니다.

* **로컬 그래프 (Local Graph):**
    * 현재 보고 있는 노트와 **직접 연결된(1 hop)** 노트들만 보여줍니다.
    * 링크된 노트나, 이 노트를 언급한 백링크 노트들이 표시됩니다.
* **글로벌 그래프 (Global Graph):**
    * 블로그에 있는 **모든 노트**의 연결 관계를 보여줍니다.
    * 전체적인 지식의 구조를 파악할 때 유용합니다.

> **💡 특징:**
> * **노트 크기:** 연결된 링크가 많을수록 노드 원이 커집니다.
> * **방문 기록:** 이미 방문했던 노트는 브라우저 링크처럼 색상이 다르게 표시됩니다.

---

## 2. 상세 설정 (Configuration)

`quartz.layout.ts` 파일의 `Component.Graph()` 안에 설정을 넣어 제어합니다. 로컬(`localGraph`)과 글로벌(`globalGraph`) 설정을 따로 할 수 있습니다.

```typescript
Component.Graph({
  localGraph: {
    drag: true,        // 그래프 드래그 이동 가능 여부
    zoom: true,        // 줌 인/아웃 가능 여부
    depth: 1,          // 보여줄 연결 깊이 (1이면 직접 연결된 것만 보임)
    scale: 1.1,        // 기본 확대 배율
    repelForce: 0.5,   // 노드끼리 밀어내는 힘 (클수록 넓게 퍼짐)
    centerForce: 0.3,  // 중앙으로 모으는 힘
    linkDistance: 30,  // 연결선의 기본 길이
    fontSize: 0.6,     // 글자 크기
    showTags: true,    // 태그도 노드로 표시할지 여부
    removeTags: [],    // 그래프에서 숨길 특정 태그 목록
  },
  globalGraph: {
    depth: -1,         // -1은 전체 노드를 다 보여준다는 뜻
    // ... 나머지 설정 동일
  },
})
````

## 3. 커스터마이징 팁

- **그래프 없애기:** `quartz.layout.ts`에서 `Component.Graph()` 부분을 삭제하면 됩니다.
    
- **태그 숨기기:** 그래프가 너무 지저분하다면 `showTags: false`로 설정하거나, `removeTags: ["daily"]` 처럼 특정 태그만 뺄 수 있습니다.
    
- **Obsidian 느낌 내기:** `enableRadial: true` 옵션을 켜면 옵시디언처럼 원형으로 정렬되는 느낌을 줍니다. (글로벌 그래프 기본값)
