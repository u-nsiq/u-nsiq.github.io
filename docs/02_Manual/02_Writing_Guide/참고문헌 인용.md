Quartz는 **BibTeX** 파일을 읽어 학술적인 인용 표기 `(Author, Year)`를 자동으로 생성해 주는 기능을 지원합니다.
연구 노트나 논문 정리를 할 때 일일이 참고문헌을 타이핑할 필요가 없습니다.

## 1. 활성화 방법 (Plugin)

이 기능은 **기본적으로 꺼져 있습니다.** 사용하려면 `quartz.config.ts` 파일에서 플러그인을 추가해야 합니다.

```typescript
// quartz.config.ts
transformers: [
  // ... 다른 플러그인들
  Plugin.Citations({
    bibliographyFile: "./bibliography.bib", // 사용할 bib 파일 경로 지정
  }),
]
````

---

## 2. 사용법 (Syntax)

### ① BibTeX 파일 준비

블로그 경로에 `.bib` 파일을 둡니다. (예: `bibliography.bib`)


```
@article{templeton2024scaling,
  title={Scaling Monosemanticity...},
  author={Templeton, Adly and ...},
  year={2024},
  // ...
}
```

### ② 본문에서 인용하기

마크다운 본문에서 `[@인용키]` 형식을 사용합니다.

- **작성:** `이 모델은 해석 가능한 특징을 추출합니다 [@templeton2024scaling].`
    
- **결과:** `이 모델은 해석 가능한 특징을 추출합니다 (Templeton et al., 2024).`
    

---

## 3. 참고문헌 목록 위치 (Reference List)

기본적으로 인용된 참고문헌 목록은 **문서의 맨 마지막**에 자동으로 생성됩니다.

만약 특정 위치에 참고문헌 목록을 넣고 싶다면, 해당 위치에 `[^ref]`라고 적어주세요.



```Markdown
# 결론
...

# 참고문헌
[^ref] 
```
