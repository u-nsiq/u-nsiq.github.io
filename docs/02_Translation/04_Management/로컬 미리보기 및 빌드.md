Quartz는 작성한 마크다운을 HTML로 변환하는 '빌드' 과정을 거칩니다.
배포하기 전에 로컬 서버를 띄워서 내 글이 잘 나오는지 실시간으로 확인할 수 있습니다.

## 1. 미리보기 명령어 (Serve)

터미널에서 다음 명령어를 입력하면, Quartz가 빌드를 수행하고 로컬 웹 서버를 실행합니다.

```bash
npx quartz build --serve
````

- **접속 주소:** 웹 브라우저를 열고 `http://localhost:8080/`으로 접속하면 내 블로그를 볼 수 있습니다.
    
- **실시간 반영:** 서버가 켜져 있는 동안 파일을 수정하고 저장하면, 브라우저가 자동으로 새로고침되어 변경 사항을 보여줍니다 (Hot-reloading).
    

> **⚠️ 주의:** 이 명령어는 오직 **로컬 테스트용**입니다. 실제 서버(Production) 용도로 사용하지 마세요.

---

## 2. 주요 옵션 (Flags)

명령어 뒤에 옵션을 붙여 동작을 제어할 수 있습니다.

|**옵션**|**설명**|**예시**|
|---|---|---|
|**`--port`**|기본 포트(8080)가 이미 사용 중일 때 다른 포트로 엽니다.|`npx quartz build --serve --port 3000`|
|**`--verbose`**|(`-v`) 빌드 과정의 로그를 더 자세히 출력합니다. 디버깅할 때 유용합니다.|`npx quartz build --serve -v`|
|**`--concurrency`**|몇 개의 스레드를 사용하여 노트를 파싱할지 정합니다. (빌드 속도 조절)|`npx quartz build --concurrency 4`|
|**`--output`**|(`-o`) 빌드 결과물이 저장될 폴더를 지정합니다. (기본값: `public`)|`npx quartz build -o my-site`|

## 3. 도움말 확인

더 많은 옵션이 궁금하다면 언제든 도움말을 확인할 수 있습니다.



```Bash
npx quartz build --help
```
