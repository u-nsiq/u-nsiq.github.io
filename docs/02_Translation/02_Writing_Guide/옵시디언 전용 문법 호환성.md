Quartz는 태생적으로 **Obsidian 볼트를 웹사이트로 배포**하기 위해 만들어진 도구입니다.
따라서 옵시디언 고유의 문법과 기능들을 별도의 변환 작업 없이 자연스럽게 지원합니다.

## 1. 주요 지원 문법 (Obsidian Flavored Markdown)

Quartz는 기본적으로 `ObsidianFlavoredMarkdown` 플러그인을 내장하고 있어, 옵시디언에서 쓰던 방식 그대로 글을 써도 웹에서 잘 보입니다.

* **위키링크 (WikiLinks):** `[[노트 제목]]` 형식으로 내부 문서를 연결하는 기능.
* **머메이드 (Mermaid):** 코드 블록을 이용해 순서도, 시퀀스 다이어그램 등을 그리는 기능.
* **기타:** 옵시디언이 지원하는 대부분의 마크다운 확장 문법(Callout 등)을 포함합니다.

## 2. 속성 파싱 (Frontmatter / Properties)

옵시디언의 **Properties(속성)** 기능을 완벽하게 지원합니다.
`Frontmatter` 플러그인이 파일 상단의 메타데이터(`--- ... ---`)를 읽어들여 제목, 날짜, 태그 등으로 변환합니다.

## 3. 링크 해결 (Link Resolution)

`CrawlLinks` 플러그인을 통해 **링크를 어떻게 찾을지** 설정할 수 있습니다.
옵시디언 설정(`Files & Links` > `New link format`)과 동일하게 동작하도록 맞출 수 있습니다.

* **Shortest:** 파일명만으로 링크 연결 (기본값)
* **Relative:** 현재 파일 위치 기준 상대 경로
* **Absolute:** 최상위 폴더 기준 절대 경로

## 4. 설정 위치

이 모든 기능은 `quartz.config.ts` 파일의 **`plugins`** 항목에 이미 등록되어 있습니다.
특별히 동작을 바꾸고 싶을 때만 해당 플러그인의 옵션을 수정하면 됩니다.
