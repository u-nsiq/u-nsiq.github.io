Quartz의 모든 콘텐츠는 `content` 폴더 안에 저장됩니다.
옵시디언(Obsidian)을 사용하여 마크다운(`.md`) 파일을 작성하면, Quartz가 이를 자동으로 정적 웹사이트로 변환합니다.

## 1. 마크다운 문법 지원

Quartz는 표준 마크다운 문법 외에도 다음 기능들을 기본적으로 지원합니다.

* **GitHub Flavored Markdown (GFM):** 표(Table), 취소선(`~~`), 체크리스트(`- [ ]`), 각주(`[^1]`) 등.
* **Obsidian Flavored Markdown:**
    * **WikiLinks:** `[[노트 제목]]` 형식의 내부 링크.
    * **Callouts:** `> [!info]` 형식의 강조 박스.

---

## 2. 프론트매터 (Frontmatter) ★ 필수

파일 맨 윗부분에 `---`로 감싸서 작성하는 메타데이터입니다. 글의 제목, 날짜, 태그 등을 설정합니다.

### 기본 예시
```yaml
---
title: "내 첫 번째 글"
date: 2026-01-30
draft: false
tags:
  - quartz
  - guide
---
````

### 주요 속성 설명

|**속성 (Key)**|**설명 및 역할**|**비고**|
|---|---|---|
|**`title`**|페이지 제목.|설정하지 않으면 **파일명**이 제목이 됩니다.|
|**`date`**|작성일 또는 수정일.|`YYYY-MM-DD` 형식 (예: `2026-01-30`).|
|**`draft`**|공개 여부 설정.|`true`: **비공개** (배포 시 제외됨)<br><br>  <br><br>`false`: **공개**|
|**`tags`**|태그 목록.|배열 형식으로 작성. (예: `[tag1, tag2]` 또는 줄바꿈 `- tag1`)|
|**`aliases`**|문서의 별칭(다른 이름).|옵시디언의 Alias 기능과 동일. 검색이나 링크 연결 시 사용됨.|
|**`description`**|페이지 요약 설명.|SEO(검색 최적화) 및 SNS 공유 시 미리보기 텍스트로 사용됨.|
|**`permalink`**|고정 URL 주소.|파일 위치가 바뀌어도 URL을 고정하고 싶을 때 사용.|
|**`cssclasses`**|커스텀 CSS 클래스.|특정 페이지만 디자인을 다르게 하고 싶을 때 사용.|

> **⚠️ 주의:** `draft: true`로 설정된 글은 로컬 미리보기(`npx quartz build --serve`)에서는 보일 수 있어도, 실제 배포(`sync`) 시에는 제외됩니다. 포스팅이 안 보인다면 가장 먼저 확인하세요!

---

## 3. 배포 및 동기화 (Syncing)

글 작성이 끝나면 터미널에서 아래 명령어를 입력하여 깃허브에 저장하고 배포합니다.



```Bash
npx quartz sync
```

- 이 명령어는 자동으로 `git add`, `commit`, `push`를 수행합니다.
