Quartz는 **빌드 타임(Build-time)** 에 코드를 미리 분석해서 색상을 입힙니다.
따라서 방문자의 브라우저에서 무거운 자바스크립트를 돌릴 필요가 없어 속도가 빠르며, VS Code와 동일한 엔진(TextMate grammar)을 사용하여 하이라이팅 품질이 매우 뛰어납니다.

## 1. 기본 사용법

백틱(\`) 3개 뒤에 언어 이름(`ts`, `py`, `c`, `cpp` 등)을 적습니다.

````markdown
```python
def hello():
    print("Hello Quartz!")
```

`````

---

## 2. 고급 기능 (Formatting)

단순히 코드만 보여주는 게 아니라, 파일명이나 특정 줄을 강조하여 가독성을 높일 수 있습니다.

### 파일 제목 표시 (Titles)
언어 뒤에 `title="..."` 속성을 추가하면 코드 블록 우측 상단에 파일명이 뜹니다.

````markdown
```ts title="quartz/path.ts"
export function trimPathSuffix(fp: string): string {
  // ...
}
```
`````

### 특정 줄 강조 (Line Highlighting)

중괄호 `{}` 안에 강조할 줄 번호를 적습니다. (범위 지정 가능)



````Markdown
```ts {2-3, 6}
// 2번부터 3번 줄, 그리고 6번 줄이 형광펜 칠한 것처럼 강조됩니다.
```
````

### 특정 단어 강조 (Word Highlighting)

슬래시 `/` 안에 강조할 단어(또는 정규표현식)를 적습니다.


````Markdown
```js /useState/
const [age, setAge] = useState(50); // useState 단어가 강조됨
```
````

### 줄 번호 설정 (Line Numbers)

특정 번호부터 줄 번호를 시작하고 싶다면 `showLineNumbers{숫자}`를 사용합니다.


````Markdown
```ts showLineNumbers{20}
// 이 줄은 20번부터 시작합니다.
```
````

## 3. 인라인 코드 하이라이팅 (Inline)

문장 중간에 들어가는 짧은 코드( )에도 색상을 입힐 수 있습니다.

코드 뒤에 `{:언어}`를 붙이면 됩니다.

- **작성:** `` `const a = 1`{:js} ``
    
- **결과:** 자바스크립트 문법 색상이 적용된 인라인 코드
    

---

## 4. 코드 블록 탈출 (Escaping)

블로그에 "코드 블록 작성법"을 설명하고 싶을 때(지금 이 문서처럼), 백틱 3개를 화면에 그대로 보여줘야 할 때가 있습니다.

이때는 **바깥쪽을 백틱 4개**로 감싸면 됩니다.



`````Markdown
````
```js
console.log("백틱 3개가 그대로 보입니다.")
```
````
`````

> **⚠️ 주의:** 코드 블록이 아주 많으면 빌드 속도가 조금 느려질 수 있습니다.
