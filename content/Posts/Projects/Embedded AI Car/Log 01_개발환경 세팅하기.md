## 2. 개발환경 세팅하기

자동차가 완성됐으니, 이제 이 위에 올라가 있는 라즈베리파이 5 보드에 접근해야 한다.

라즈베리파이는 간단하게 말하면 작은 컴퓨터다. CPU, RAM, 저장소가 다 들어있는데, 저장소 역할을 하는 것은 SD 카드다. 일반 데스크탑의 하드디스크 자리에 SD 카드가 들어간다고 보면 된다.
참고로 내 라즈베리파이 5 보드에 꽂혀 있는 SD 카드는 16GB이다.

### 2.1. SD 카드에 OS 설치하기
이 라즈베리파이 보드도 컴퓨터이기 때문에, OS를 설치해야 한다. 이 OS는 [Raspberry Pi Imager](https://www.raspberrypi.com/software/)라는 소프트웨어로 SD 카드에 설치할 수 있다.

![[Pasted image 20260416175103.png]]
> Raspberry Pi Imager 사이트 모습.

Imager로 OS 설치할 때, 아래와 같이 OS Customization에서 몇 가지 설정해야 하는 것이 있다:

1. 계정 설정: 계정 이름 · 비밀번호
2. Wi-Fi 설정: SSID · 비밀번호

![[Pasted image 20260416180014.png|500]]
> Imager로 OS 계정 설정하는 창.

이건 그냥 Windows로 치면 Window Hello 같은 것이다.
라즈베리파이에 설치될 OS에 우리가 로그인할 때 쓸 아이디와 비밀번호다.
나중에 ssh나 vnc로 접근할 때 이 ID와 PW를 사용하여 로그인할 수 있다.


![[Pasted image 20260416180041.png|500]]
> Imager로 OS Wi-Fi 설정하는 창.

이건 라즈베리파이 OS에 네트워크를 연결하기 위한 작업이다.
라즈베리파이 보드는 부팅이 되면 자동으로 네트워크를 탐색하는데, 그때 저 SSID와 PW를 등록해두면, 그 SSID에 해당하는 Wi-Fi를 찾아서 자동으로 PW를 입력하여 연결하게 된다.
참고로 SSID는 Service Set IDentifier의 약자로, Wi-Fi 이름에 해당한다.

이제 노트북으로 핫스팟을 킬 때, 라즈베리파이 OS에 등록한 SSID와 PW로 속성을 변경해서 핫스팟을 키면 라즈베리파이가 내 노트북 핫스팟에 연결된다.


>[!tip] TIP
> 더 자세한 내용은 Raspberry Pi Documentation 참고.
> [Raspberry Pi Doc — Getting Started](https://www.raspberrypi.com/documentation/computers/getting-started.html)


이제 이 설정으로 SD카드에 OS를 구우면 된다.

### 2.2. 라즈베리파이 OS에 네트워크 연결

이제 OS에 설정한 SSID와 PW로 모바일 핫스팟을 키고, 라즈베리파이 보드에 전원을 넣으면 보드가 네트워크에 연결된다.

![[Pasted image 20260416182541.png|500]]
> 노트북 모바일 핫스팟 설정 창.

보드가 핫스팟에 연결되면 Windows 핫스팟 설정 화면에 연결된 장치와 IP 주소가 보인다. 이 IP 주소가 앞으로 모든 원격 접속에 쓰이게 된다.

### 2.3. 라즈베리파이 OS에 SSH 접속

이제 OS는 부팅과 함께 네트워크까지 연결된 상태다. 이 라즈베리파이 OS에 터미널로 접속해 볼 수 있다.

아래 명령어로 접속한다.

```bash
ssh [사용자 이름]@[IP 주소]
```

참고로 SSH는 Secure Shell의 약자로, 다른 컴퓨터에 안전하게 원격 접속할 수 있는 통신 규약이다.

아까 전 OS에 입력했던 `username`과 핫스팟 창에 있는 `IP 주소`를 입력하고, `password`를 입력하면 라즈베리파이 OS에 로그인한 것이다.

로그인에 성공하면 터미널에 다음과 같이 뜬다:
```Shell
pi@team3:~ $
```

여기서 명령어를 실행하면 실제로 Pi 위에서 돌아간다.

### 2.4. VNC 설정

SSH는 터미널만 보인다. 카메라 영상처럼 GUI 결과를 보려면 VNC가 필요하다. VNC는 Pi의 바탕화면 전체를 네트워크 너머로 보여주는 방식이다.

라즈베리파이 OS는 기본으로 VNC가 꺼져 있다. SSH로 들어가서 직접 켜야 한다.

```bash
sudo raspi-config
```


![[Pasted image 20260416184030.png|600]]
명령어를 입력하면 이런 config 창으로 터미널 화면이 바뀐다.

여기서 먼저 `Advanced Options → Wayland`로 들어가면 기본값이 `Wayfire`로 설정되어 있다. 이걸 `X11`로 바꿔야 한다.
Wayfire 환경에서는 VNC가 화면을 네트워크 너머로 전송하지 못해 `X11`로 바꿔야 한다.

![[Pasted image 20260416184150.png|600]]
![[Pasted image 20260416184159.png|600]]


X11로 바꾼 뒤 `Interface Options → VNC → Enable`로 활성화한다. Finish를 누르면 재부팅된다.

![[Pasted image 20260416184349.png|600]]

![[Pasted image 20260416184409.png|400]]

VNC는 쉽게 말해서 라즈베리파이 OS의 화면을 내 모니터로 그대로 가져와서 제어할 수 있는 도구라고 생각하면 된다.

### 2.6. VS Code Remote-SSH

VNC로 라즈베리파이 바탕화면에 접근은 됐는데, 코드 작성을 VNC 위에서 Thonny IDE로 하는 건 좀 불편하다.
프로젝트 수행하며 제공된 튜토리얼 파일에선 그 방식으로 안내하는데, 난 그냥 내 노트북 VS Code에서 바로 작업하는 게 훨씬 나을 것 같아서, 이 방법을 사용했다.

VS Code의 Remote - SSH 확장을 쓰면, 편집은 내 노트북 VS Code에서 하면서 파일 저장과 코드 실행은 실제로 Pi 위에서 이루어지는 구조가 된다.

먼저 VS Code Extensions에서 Remote - SSH를 검색해서 설치한다.

![[Pasted image 20260416185933.png|600]]
> Remote - SSH 확장 설치 화면.

설치가 됐으면, 좌하단 `><` 아이콘을 클릭하고 `Connect to Host → Add New SSH Host`를 선택한다. 커맨드 팔레트에 아래와 같이 입력한다.

![[Pasted image 20260416190111.png|400]]

```bash
ssh pi@[IP 주소]
```

![[Pasted image 20260416190155.png|500]]
> SSH 호스트 추가 커맨드 팔레트.

이제 다시 `><` 아이콘 → `Connect to Host`에서 방금 추가한 호스트를 선택하면 새 창이 열리면서 비밀번호를 묻는다. OS 설정 때 입력했던 비밀번호를 입력하면 연결된다.

연결이 되면 좌하단에 `SSH: [IP 주소]` 표시가 뜬다. 여기서 `File → Open Folder`로 Pi OS의 폴더들이 VS Code 탐색기에 바로 보인다.

![[Pasted image 20260416190353.png|500]]

## 마무리

이렇게 자동차 조립, Pi OS 설치 및 연결을 수행했고, 개발환경 세팅까지 마무리 했다.

프로젝트 첫 시작이라 일단 여기까지만 해서 시작을 위한 준비만 했다.
사실 Raspberry Pi, SSH ,VNC 다 처음 들어보고 보드에 네트워크 연결해서 접속해본게 처음이었다.
원리 자체는 그리 어렵지 않아서 금방 이해하고 환경을 구축할 수 있었다.

아마 다음엔 프로젝트 파악도 할겸 전체적인 그림을 그리면서 우리는 어떤 식으로 데이터 수집하고 모델 학습시킬 지 등의 아키텍처를 계획하지 않을까 싶다.
