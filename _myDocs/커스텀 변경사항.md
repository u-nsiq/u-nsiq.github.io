# Quartz 커스텀 변경사항

Default Quartz 4 대비 직접 수정한 내용을 정리한다.
마지막 업데이트: 2026-04-27 (4차 — Explorer UX / RecentNotes / 접근성)

---

## 0. 읽는 법 / 이력 / 파일 의존도

각 섹션은 **무엇을 바꿨는가** → **왜** → **어떻게**(파일 위치) 순서로 쓴다.
업스트림(`npx quartz update`) 충돌 주의 파일은 ⚠️ 표시.

### 변경 이력

| 날짜 | 변경 내용 |
|---|---|
| 2026-04-08 | 초기 작성 |
| 2026-04-22 | Explorer 폴더 클릭 UX 개선(C안), 드로어 줌 버그 수정, 스타일 조정 |
| 2026-04-22 | 좌/우 사이드바 폭 분리 (당시 `$leftPanelWidth: 340px`로 기록 — 실제는 320px, 3차 리팩토링에서 정정) |
| 2026-04-27 | **3차 리팩토링**: 드로어 SCSS/TS 분리, Explorer 옵션 단일 출처화, [커스텀] 마커 정비, 거짓 기록(📁 mapFn) 제거 |

### 파일 의존도

```
custom.scss ──@use──> _drawer.scss ──@use──> _drawer-vars.scss
                          │
                          └─ z-index/폭/트랜지션 단일 출처
                                                │
variables.scss ($leftPanelWidth = 320px) ─keep-in-sync─┘

explorer.inline.ts ──import──> _drawer.ts <──import── toc.inline.ts
                       ↑
                       └─ togglePanel / closeAllPanels /
                          registerOverlayClickHandler / PANEL_OPEN_CLASS

quartz.layout.ts (Explorer 옵션 단일 출처: explorerCommonOptions)
   ↓ data-state-overrides / data-data-fns
Explorer.tsx ──> explorer.inline.ts setupExplorer()
```

`.panel-open`은 SCSS-JS **계약 클래스**다. JS 측은 `PANEL_OPEN_CLASS` 상수로
단일화했지만 CSS 셀렉터에는 문자열로 남아 있으니 이름 변경 시 두 곳 모두 수정.

## 2. 드로어 레이아웃 시스템

### 2-1. 배경과 목적

화면 분할/줌(75~80%)으로 1200px 미만이 되면 Quartz는 모바일 모드로 들어가
Explorer가 화면 전체를 덮는다 → 콘텐츠가 잘리고 레이아웃이 어색.

해결: 1200px 미만에서는 사이드바를 **off-screen 고정 패널(드로어)**로 두고,
좌상단·우상단 버튼으로만 슬라이드 토글한다.

- 좌버튼(☰) → Explorer 드로어
- 우버튼(≡) → TOC + Graph + Backlinks 드로어

### 2-2. `.collapsed` vs `.panel-open` — 핵심 개념

Quartz 원본은 `.collapsed`로 Explorer 접기/펼치기를 관리한다. 이걸 그대로 쓰면
**zoom/resize 이벤트가 자동으로 `.collapsed`를 추가**해 드로어가 닫혀버린다.

→ `.panel-open`이라는 별도 클래스를 도입:

| 트리거 | 동작 |
|---|---|
| 드로어 버튼 클릭 | `.panel-open` 토글 |
| nav (페이지 이동) | `.panel-open` 제거 (자동 닫힘) |
| 오버레이 클릭 | `.panel-open` 제거 |
| zoom/resize | **무동작** (의도적 no-op) |

JS 측에서는 `_drawer.ts`의 `PANEL_OPEN_CLASS = "panel-open"` 상수로 단일화.

### 2-3. 파일 분리 구조 (3차 리팩토링)

```
quartz/styles/
  custom.scss           ← @use _drawer.scss + 콘텐츠/Explorer item 스타일
  _drawer.scss          ← §1·§1-B 드로어 레이아웃 (mixin: drawer-button)
  _drawer-vars.scss     ← 변수 단일 출처 (폭, z-index, 트랜지션, 패딩)

quartz/components/scripts/
  explorer.inline.ts    ← 헬퍼 import + Explorer 본체
  toc.inline.ts         ← 헬퍼 import + TOC 본체
  _drawer.ts            ← togglePanel / closeAllPanels / registerOverlayClickHandler
                          (※ .inline.ts 아님 — 일반 모듈, esbuild bundle:true가 인라이닝)
```

`.inline.ts`는 각각 독립 esbuild 번들이지만 `bundle: true` 설정 덕에 sibling
모듈을 import하면 트리쉐이킹/인라이닝된다. (`quartz/cli/handlers.js`의
`inline-script-loader` 참고.)

### 2-4. SCSS 변수 (`_drawer-vars.scss`)

| 변수 | 값 | 의미 |
|---|---|---|
| `$drawer-breakpoint` | `1199px` | 이 값 이하에서 드로어 모드 진입 |
| `$drawer-mobile-collision` | `799px` | Quartz `$mobile`(800px) 누수 차단 블록 진입 |
| `$drawer-width-left` | `320px` | 좌 드로어 폭 (variables.scss `$leftPanelWidth`와 일치) |
| `$drawer-width-right` | `320px` | 우 드로어 폭 (variables.scss `$sidePanelWidth`와 일치) |
| `$drawer-z-overlay` | `199` | 오버레이(딤) |
| `$drawer-z-panel` | `200` | 드로어 패널 |
| `$drawer-z-button` | `201` | 드로어 버튼 (항상 최상단) |
| `$drawer-transition-slide` | `200ms ease` | 패널 슬라이드 |
| `$drawer-transition-overlay` | `200ms ease` | 오버레이 페이드 |
| `$drawer-transition-button` | `150ms ease` | 버튼 색상 |

`@mixin drawer-button-active($icon-selector)`로 통합 (각 1회 호출).

### 2-5. 줌 인 시 드로어 깨짐 (§1-B 블록)

Quartz `$mobile = 800px`가 드로어 브레이크포인트(1200px)보다 좁아서, 드로어
열린 상태에서 줌 인 → 뷰포트가 800px 아래로 가면 `base.scss` / `explorer.scss`의
`@media ($mobile)` 규칙이 추가 발동:

- `.sidebar.left { flex-direction: row; gap: 0; height: unset }` → 세로 레이아웃 붕괴
- `.explorer { flex: 0 0 34px; overflow: hidden; order: -1 }` → 34px로 찌그러짐
- `.explorer-content` full-screen overlay 변환 → 콘텐츠 잘림
- `MobileOnly(Spacer)` 표시 → `flex: 1`로 공간 잠식

`_drawer.scss` §1-B (`@media (max-width: 799px)`)에서 위 모든 사항을
명시적으로 다시 덮어쓴다 (§1과 일부 규칙 중복하지만 `!important` 캐스케이드
우위를 위해 의도적 재선언).

## 3. Explorer 커스텀 기능

### 3-1. 폴더 카운트 + 최근 업데이트 dot

**파일 카운트 (`folder-count`)**
- `countFiles(node)` 로 폴더 전체 파일 수를 계산해 제목 옆에 회색 숫자 표시.
- CSS: `explorer.scss` `[커스텀 BEGIN]` 블록의 `.folder-count`.

**빨간 dot (`folder-recent-dot`)**
- RecentNotes 컴포넌트와 동일 기준으로 상위 `DOT_LIMIT`(현재 3)개 파일을 포함한
  폴더에 5px 빨간 원 표시.
- 로직: `explorer.inline.ts`의 `setupExplorer`에서 `contentIndex.json`의 `date`
  필드를 내림차순 정렬 → 상위 3개 slug Set → `hasRecentFile(node, recentSlugs)`.
- **index 페이지 제외**: `contentIndex.json`에서 index.md는 빌드 타임 날짜가 들어가
  항상 최상위를 차지하므로 `slug === "index"` 또는 `slug.endsWith("/index")`인 항목은
  정렬 전 필터링.
- `hasRecentFile`: 파일 노드면 `recentSlugs.has(node.slug)`, 폴더면 자식 재귀.
- CSS: `explorer.scss` `[커스텀 BEGIN]` 블록의 `.folder-recent-dot`.

### 3-2. `folderStateOverrides`

- 옵션은 `Explorer.tsx`의 `Options` 인터페이스에 추가되어 `data-state-overrides`
  속성으로 직렬화 → `explorer.inline.ts`가 JSON 파싱해 폴더별 초기 상태 결정.
- `explorerCommonOptions.folderStateOverrides`로 단일 출처화 →
  `quartz.layout.ts`에서 `Notes: collapsed`, `Posts: open` 지정.

### 3-3. 폴더 클릭 UX

**현재 동작 (4차)**

| 폴더 종류 | 제목 텍스트 클릭 | 화살표 아이콘 클릭 |
|---|---|---|
| index.md **있음** | index.md 페이지로 이동 | 펼치기/접기 |
| index.md **없음** | 펼치기/접기 | 펼치기/접기 |

- `createFolderNode`의 `else`(collapse) 분기에서 `node.data !== undefined`이면
  `<button.folder-button>`을 `<a.folder-title-link>`으로 교체.
  `<a>`는 기존 `& div > a` CSS 규칙을 자동 상속(secondary 색상, semibold 등).
- index.md 없는 폴더는 `<button.folder-button>` 유지 → `toggleFolder` 이벤트 정상 동작.
- 화살표 아이콘 개선: `Explorer.tsx`에서 SVG 12px → 16px,
  `explorer.scss`에서 `padding: 4px; border-radius: 4px` + hover 시
  `background-color: var(--highlight)` 배경 하이라이트.

### 3-4. 드로어 버튼 바인딩

Explorer 버튼 분기 (`setupExplorer`):

| `data-mobile` | 핸들러 | 동작 |
|---|---|---|
| `"true"` | `toggleExplorerPanel` | `togglePanel(this, ".explorer")` (panel-open) |
| 없음 | `toggleExplorer` | 원본 `.collapsed` 토글 (데스크탑 fold) |

`toggleExplorerPanel` / `toggleTocPanel` 본문은 모두 `_drawer.ts`의
`togglePanel(this, selector)` 한 줄로 대체.

| 이벤트 | 처리 |
|---|---|
| `nav` (페이지 이동) | `closeAllPanels(".explorer")` / `closeAllPanels(".toc")` (`checkVisibility()` 가드 보존) |
| `resize` | **의도적 no-op** (zoom 시 드로어 유지) |
| `document` 클릭 | `registerOverlayClickHandler()` (멱등 — 여러 번 호출돼도 1회만 등록). `.sidebar.left/.right` 바깥 클릭 시 해당 패널 닫기 |

### 3-5. `contentIndex.tsx` date 필드 유지 ⚠️

원본은 `simplifiedIndex` 생성 시 `delete content.description`과 함께
`delete content.date`도 수행. 우리는 `delete content.date`를 **제거**(=date 보존):

- `sortFn`이 `node.data.date`로 frontmatter 날짜에 접근해 내림차순 정렬
- `countRecentFiles`가 동일 필드로 최근 N일 카운트

해당 라인 위에 `// [커스텀]` 마커 추가.

> ※ 이전 문서에 있었던 "mapFn으로 폴더 이름에 📁 이모지 추가" 항목은
> 실제 코드에 존재하지 않는 거짓 기록이라 3차 리팩토링에서 삭제했다.

## 4. 콘텐츠 스타일 (`custom.scss` §2·§3)

### 본문

| 항목 | 적용 |
|---|---|
| 본문 굵기 | `article { font-weight: 450 }` (Pretendard variable의 중간 weight) |
| 볼드 | `article strong { font-weight: 700 }` |
| `[[내부 링크]]` | `article a.internal { color: var(--dark) }` (라이트 배경 가독성) |
| `==하이라이트==` | 라이트 `font-weight: 600` / 다크 `color: #1a1a1a; font-weight: 600` |
| inline code | 라이트 `rgb(233, 49, 58)` / 다크 `rgb(255, 110, 110)` |
| 텍스트 선택 | 라이트 `rgba(0,0,0,0.12)` / 다크 `rgba(255,255,255,0.15)` |
| 중첩 목록 들여쓰기 가이드 | Obsidian 스타일 — `ul > li:has(> ul/ol)::after` + `ol > li:has(> ul/ol)::after` 세로 라인 |

### Explorer item

- `.explorer-content ul li > a`: `0.75rem`, `display: block` (클릭 영역 확장),
  hover/active 시 배경 `var(--highlight)`, `border-radius: 3px`,
  `transition: background-color 100ms ease`.
- `.explorer-content ul li`: `margin-bottom: 0.1rem` (구분선 대신 spacing).

### RecentNotes 사이드바 (`custom.scss §4`)

- 좌측 사이드바 하단에 최근 노트 3개 고정 표시.
- `quartz.layout.ts`의 `RecentNotes` 컴포넌트: `limit: 3`, `showTags: false`,
  `filter: !draft && slug !== "index" && !slug.endsWith("/index")`.
- 사이드바 하단 고정: `.sidebar.left`가 `flex-direction: column; height: 100vh`이므로
  `margin-top: auto`로 `.recent-notes`를 아래로 밀착. 데스크톱 전용(`not ($mobile)` 조건).
- `$mobile` 변수 사용을 위해 `custom.scss` 상단에 `@use "./variables.scss" as *` 추가.

### 접근성 (`prefers-reduced-motion`)

- `_drawer.scss`: 드로어 오버레이·패널 슬라이드 트랜지션 비활성화.

## 7. 코드 리뷰 (이슈 / 충돌 위험 / 개선)

### 7-1. 3차 리팩토링에서 해결

- 320 vs 340 드리프트 정정 — **모든 곳을 320으로 통일**, 문서 거짓 기록 제거.
- `sortFn` / `folderStateOverrides` 13줄+4줄 verbatim 중복 제거 (`explorerCommonOptions`).
- 드로어 토글 함수 두 inline.ts에 중복 → `_drawer.ts.togglePanel`로 단일화.
- 드로어 버튼 CSS 좌·우 거의 동일 → `@mixin drawer-button` 1회 호출 × 2.
- 매직 넘버(1200/800/340/320, z-index, ms) → `_drawer-vars.scss` 변수로 추출.
- 인라인 SVG 문자열·"인덱스 페이지로 이동" → `LINK_ICON_SVG` / `LINK_ICON_TITLE` 상수.
- 7일 컷오프 → `RECENT_FILE_DAYS` / `RECENT_FILE_CUTOFF_MS` 상수.
- 오버레이 클릭 핸들러 → `registerOverlayClickHandler()` 멱등 함수로 정리.
- 각 파일 상단에 **CUSTOM CHANGES INDEX** 헤더 추가.
- 거짓 기록 제거: "mapFn 폴더 이름에 📁 이모지" — 구현된 적 없음.

### 7-2. 알려진 충돌 위험 (남아있는 것)

- **`.panel-open` 클래스 이름은 SCSS-JS 계약**. JS는 `PANEL_OPEN_CLASS` 상수로
  단일화했지만 CSS는 여전히 문자열 셀렉터. 향후 `data-panel="open"`
  attribute 기반으로 옮기는 안 검토.
- **`!important` 약 30건**은 `base.scss` / `explorer.scss`의 `@media ($mobile)`
  규칙을 이기기 위함. 업스트림 specificity 변경 시 깨질 수 있음.
- **1200px 드로어 vs 800px `$mobile`** 브레이크포인트 충돌은 구조적.
  `$mobile`을 1200px로 올리면 부작용이 큼 → 현재 §1-B 리셋 블록으로 우회.
- **`.inline.ts` ↔ `_drawer.ts` import**는 esbuild `bundle: true`에 의존.
  Quartz가 번들러를 바꾸면 점검 필요.
- `data-data-fns`로 `sortFn`을 `Function` 생성자로 역직렬화 → `explorerSortFn`은
  외부 변수를 closure로 잡으면 안 됨 (자체 완결적이어야 함).
- **`DOT_LIMIT`과 RecentNotes `limit`은 별개**. 현재 둘 다 3이지만 각자 독립적으로
  관리된다. `DOT_LIMIT`은 `explorer.inline.ts` 상단, `limit`은 `quartz.layout.ts`.
