Quartz는 다른 컴포넌트들을 감싸서(Wrap) **배치를 조정하거나, 화면 크기에 따라 보여주고 숨기는** 기능을 하는 '고차 컴포넌트'를 제공합니다. `quartz.layout.ts`에서 화면을 구성할 때 핵심적으로 사용됩니다.

## 1. `Flex` Component (유연한 배치)

[CSS Flexbox](https://developer.mozilla.org/en-US/docs/Web/CSS/flex) 기술을 사용하여 하위 컴포넌트들을 가로 또는 세로로 정렬합니다. 반응형 레이아웃을 만들 때 가장 많이 쓰입니다.

### 설정 옵션
```typescript
type FlexConfig = {
  components: {
    Component: QuartzComponent
    grow?: boolean   // 남은 공간을 채울지 여부 (flex-grow)
    shrink?: boolean // 공간이 부족하면 줄어들지 여부 (flex-shrink)
    basis?: string   // 초기 크기 (flex-basis)
    order?: number   // 배치 순서
    align?: "start" | "end" | "center" | "stretch" // 수직 정렬 (cross-axis)
    justify?: "start" | "end" | "center" | "between" | "around" // 수평 정렬 (main-axis)
  }[]
  direction?: "row" | "row-reverse" | "column" | "column-reverse" // 배치 방향
  wrap?: "nowrap" | "wrap" | "wrap-reverse" // 줄바꿈 여부
  gap?: string // 컴포넌트 사이 간격 (예: "1rem")
}
````

### 사용 예시

검색창(`Search`)과 다크모드 버튼(`Darkmode`)을 가로로 배치하고, 검색창이 남은 공간을 꽉 채우게 하는 코드입니다.


```TypeScript
Component.Flex({
  components: [
    {
      Component: Component.Search(),
      grow: true, // 검색창이 길어짐
    },
    { Component: Component.Darkmode() }, // 버튼 크기 유지
  ],
  direction: "row", // 가로 배치
  gap: "1rem", // 사이 간격
})
```

## 2. 반응형 제어 (`MobileOnly` / `DesktopOnly`)

화면 크기에 따라 컴포넌트를 보여주거나 숨깁니다. Quartz의 반응형 디자인을 구현하는 핵심 도구입니다.

### `MobileOnly`

자식 컴포넌트를 **모바일 기기에서만** 보여줍니다. (화면이 작을 때)

- **용도:** 모바일 전용 햄버거 메뉴, 공간 확보를 위한 `Spacer` 등.
    
- **예시:** `Component.MobileOnly(Component.Spacer())`
    

### `DesktopOnly`

자식 컴포넌트를 **데스크톱 기기에서만** 보여줍니다. (화면이 클 때)

- **용도:** 공간을 많이 차지하는 목차(TOC), 그래프 뷰 등.
    
- **예시:** `Component.DesktopOnly(Component.TableOfContents())`

## 3. `ConditionalRender` (조건부 렌더링)

특정 조건(함수 결과)이 `true`일 때만 컴포넌트를 표시합니다.

### 설정 옵션



```TypeScript
type ConditionalRenderConfig = {
  component: QuartzComponent
  condition: (props: QuartzComponentProps) => boolean // true면 렌더링
}
```

### 사용 예시 1: 홈 화면에서만 숨기기

경로 표시(`Breadcrumbs`)는 홈 화면(`index`)에서는 굳이 필요 없으므로 숨길 때 사용합니다.



```TypeScript
Component.ConditionalRender({
  component: Component.Breadcrumbs(),
  condition: (page) => page.fileData.slug !== "index", // 슬러그가 'index'가 아닐 때만 true
})
```

### 사용 예시 2: 전체 화면 모드 아닐 때만 검색창 표시



```TypeScript
Component.ConditionalRender({
  component: Component.Search(),
  condition: (props) => props.displayClass !== "fullpage",
})
```
