Quartz 4를 사용하다가 최신 기능(업데이트)을 적용하고 싶을 때 사용하는 방법입니다.

## 1. 업데이트 명령어

터미널에서 다음 명령어를 실행하면 됩니다.

```bash
npx quartz update
````

### 작동 원리

Quartz는 내부적으로 **Git**을 사용하여 버전을 관리합니다.

위 명령어는 공식 Quartz 저장소(upstream)의 최신 변경 사항을 내 로컬 저장소로 **Pull(당겨오기)** 하는 역할을 합니다.

---

## 2. 충돌 해결 (Merge Conflicts)

만약 사용자님이 `quartz.layout.ts`나 특정 컴포넌트 코드를 많이 수정했는데, 원본 Quartz에서도 해당 파일이 업데이트되었다면 **충돌(Conflict)**이 발생할 수 있습니다.

### 안전 장치 (Restore)

Quartz는 업데이트를 시작하기 전에 현재 상태를 임시로 캐싱(백업)해 둡니다.

만약 업데이트 도중 문제가 생기거나 충돌 해결이 어렵다면, 다음 명령어로 업데이트 전 상태로 되돌릴 수 있습니다.



```Bash
npx quartz restore
```

### 수동 해결 방법

충돌이 발생하면 **VS Code**나 **GitHub Desktop** 같은 도구를 사용하여 충돌된 코드(`<<<<`, `====`, `>>>>`)를 직접 수정하고 병합(Merge)해야 합니다.

> **💡 참고:** 단순히 글만 쓰고 설정 파일 정도만 건드렸다면, 대부분의 경우 충돌 없이 매끄럽게 업데이트됩니다.
