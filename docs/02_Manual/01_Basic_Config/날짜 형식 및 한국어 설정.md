Quartz는 `locale` 설정을 통해 블로그의 **기본 언어**와 **날짜 표기법**을 결정합니다. 코드를 뜯어고치지 않아도 설정 한 줄로 사이트 전체의 언어 환경을 바꿀 수 있습니다.

## 1. 기본 설정 방법

`quartz.config.ts` 파일의 `configuration` 객체 안에서 `locale` 값을 수정합니다.

```typescript
// quartz.config.ts
const config: QuartzConfig = {
  configuration: {
    // ...
    locale: "ko-KR", // 한국어 설정 예시
    // ...
  },
}
````

### Locale 형식 규칙

`{언어}-{지역}` 형식을 따릅니다.

- **`{언어}`**: 2글자 소문자 언어 코드 (예: `en`, `ko`)
    
- **`{지역}`**: 2글자 대문자 국가 코드 (예: `US`, `KR`)
    

---

## 2. 주요 설정값 비교

사용자님(개발자/연구생)이 가장 많이 고민할 두 가지 옵션의 차이점입니다.

|**설정값**|**en-US (기본값)**|**ko-KR (한국어)**|
|---|---|---|
|**날짜 표기**|`Jan 30, 2026`|`2026년 1월 30일`|
|**검색창**|`Search`|`검색`|
|**목차**|`Table of Contents`|`목차`|
|**그래프**|`Graph View`|`그래프 보기`|
|**백링크**|`Backlinks`|`백링크`|
|**읽는 시간**|`1 min read`|`1분 분량`|

> **💡 추천:**
> 
> - **"개발자 감성(영어 메뉴)"**을 원한다면 **`en-US`**
>     
> - **"친절한 한국어 블로그"**를 원한다면 **`ko-KR`**
>     

---

## 3. (심화) 커스텀 번역 적용하기

만약 **"메뉴는 영어(`Graph View`)로 쓰고 싶은데, 날짜만 한국식(`2026년...`)으로 바꾸고 싶다"**거나, 그 반대의 경우라면 직접 번역 파일을 수정해야 합니다.

1. `quartz/i18n/locales/` 폴더로 이동합니다.
    
2. `en-US.ts` 파일을 복사해서 `my-custom.ts` 같은 새 파일을 만듭니다.
    
3. 파일 안의 내용을 원하는 대로 수정합니다. (예: 날짜 포맷 함수만 수정하거나, 텍스트만 수정)
    
4. `quartz/i18n/index.ts` 파일에 내 커스텀 파일을 등록합니다.
    
5. `quartz.config.ts`에서 `locale: "my-custom"`으로 설정합니다.
    

TypeScript

```
// 예시: quartz/i18n/locales/ko-KR.ts 내부 구조
export default {
  propertyDefaults: {
    title: "제목 없음",
    description: "설명 없음",
  },
  components: {
    callout: {
      note: "노트",
      // ...
    },
    // ...
  },
} as const
```
