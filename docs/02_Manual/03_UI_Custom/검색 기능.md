Quartz는 **Flexsearch** 엔진을 탑재하여, 문서가 수십만 개라도 0.01초(10ms) 이내에 결과를 찾아내는 강력한 전체 텍스트 검색 기능을 제공합니다.

## 1. 사용법 및 단축키

마우스로 돋보기 아이콘을 클릭하거나, 키보드 단축키를 사용할 수 있습니다.

| 기능 | Windows / Linux | macOS | 비고 |
| :--- | :--- | :--- | :--- |
| **검색창 열기** | `Ctrl` + `K` | `Cmd` + `K` | |
| **태그 검색** | `Ctrl` + `Shift` + `K` | `Cmd` + `Shift` + `K` | 또는 검색창에 `#` 입력 후 검색 |
| **결과 이동** | 방향키 (`↑`, `↓`) | 방향키 (`↑`, `↓`) | `Enter`로 선택 |

---

## 2. 검색 원리 (Indexing)

* **한글 지원:** Quartz는 한국어, 중국어, 일본어(CJK) 토큰화를 지원하여 한글 검색이 정확하게 작동합니다.
* **우선순위:** 본문 내용보다 **문서 제목(Title)**이 일치할 때 더 높은 점수를 줍니다.
* **제외 대상:** 마크다운 문법(링크 URL 등)은 제거하고 순수 텍스트만 인덱싱합니다.

> **⚠️ 필수 조건:** 검색 기능이 작동하려면 `quartz.config.ts`의 플러그인 목록(`emitters`)에 **`ContentIndex`** 플러그인이 반드시 포함되어 있어야 합니다.

---

## 3. 커스터마이징

### 활성화/비활성화
`quartz.layout.ts` 파일에서 `Component.Search()`를 추가하거나 삭제하여 검색창을 제어합니다.

### 결과 개수 조절 (고급)
기본적으로 상위 5개의 결과만 보여줍니다. 이 숫자를 바꾸고 싶다면 소스 코드를 직접 수정해야 합니다.

* **파일 위치:** `quartz/components/scripts/search.inline.ts`
* **수정 변수:**
    * `numSearchResults`: 보여줄 검색 결과 개수 (기본 5개)
    * `contextWindowWords`: 미리보기에 보여줄 단어 수 (기본 30개)

```typescript
// quartz/components/scripts/search.inline.ts 예시
// ...
const numSearchResults = 10 // 5개에서 10개로 늘리기
// ...
````
