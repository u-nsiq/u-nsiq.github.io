Breadcrumbs(빵 부스러기)는 사용자가 현재 블로그의 **어느 폴더 위치에 있는지**를 계층 구조로 보여주는 내비게이션 바입니다.
보통 페이지 제목 바로 위에 `Home > 상위 폴더 > 현재 페이지` 형태로 표시됩니다.

## 1. 상세 설정 (Configuration)

`quartz.layout.ts` 파일에서 `Component.Breadcrumbs()` 안에 옵션을 넣어 제어합니다.

```typescript
Component.Breadcrumbs({
  spacerSymbol: "❯", // 경로 사이의 구분 기호 (예: /, >, ->)
  rootName: "Home", // 최상위(루트)의 이름 (예: "블로그", "Main")
  resolveFrontmatterTitle: true, // 폴더명을 그대로 쓸지(false), index.md의 제목을 쓸지(true)
  showCurrentPage: true, // 경로 맨 끝에 현재 페이지 제목을 보여줄지 여부
})
````

> **💡 팁:** `resolveFrontmatterTitle: true`로 설정하는 것을 추천합니다.
> 
> 이렇게 하면 폴더 이름이 영어(`dev-notes`)라도, 해당 폴더 안의 `index.md` 제목이 "개발 노트"라면 경로에 **"개발 노트"**라고 예쁘게 표시됩니다.

---

## 2. 위치 변경 및 삭제

- **위치 이동:** `quartz.layout.ts`의 `beforeBody` 배열 안에서 컴포넌트 순서를 바꾸면 위아래 위치가 조정됩니다.
    
- **삭제하기:** `Component.Breadcrumbs()` 코드를 아예 지우면 상단 경로가 사라집니다.
